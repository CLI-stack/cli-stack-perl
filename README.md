# Perl Beginner Lessons — 100 Examples

A structured Perl learning curriculum with 100 example scripts across 14 topic branches.

## Lesson Branches

| # | Directory | Topics |
|---|-----------|--------|
| 01 | `01_basics/` | Hello World, Variables, Input, Comments, Strings, print/say, chomp, undef |
| 02 | `02_strings/` | String ops, length, index, substr, split, join, reverse, repeat, sprintf |
| 03 | `03_numbers/` | Arithmetic, Comparison, Math functions, Random numbers, Hex/Oct/Bin |
| 04 | `04_arrays/` | Array basics, push/pop, shift/unshift, slices, sort, grep, map, splice |
| 05 | `05_hashes/` | Hash basics, operations, iteration, delete/exists, Hash of Arrays, word count |
| 06 | `06_control_flow/` | if/elsif, unless, ternary, for, foreach, while, do-while, last/next, dispatch tables |
| 07 | `07_subroutines/` | Basic subs, arguments, return values, defaults, recursion, anonymous subs, closures |
| 08 | `08_file_io/` | Read files, write files, append, file tests, line-by-line, directory ops, copy/delete |
| 09 | `09_regex/` | Match, substitution, global replace, capture groups, modifiers, lookahead, validation |
| 10 | `10_references/` | Scalar refs, array refs, hash refs, nested structures, code refs |
| 11 | `11_modules/` | strict/warnings, POSIX, List::Util, Scalar::Util, Data::Dumper, File::Basename, Time |
| 12 | `12_system/` | system(), backticks, env vars, @ARGV, exit codes, pipes |
| 13 | `13_text_processing/` | Word count, log parser, CSV processor, find/replace, line numbering, column extract |
| 14 | `14_error_handling/` | die/warn, eval block, error patterns, Carp module, Capstone project |

## How to Run

```bash
perl 01_basics/01_hello_world.pl
perl 09_regex/61_basic_match.pl
```

## Prerequisites

- Perl 5.10+ (for `say`, `state`, `//`)
- Core modules: `List::Util`, `Scalar::Util`, `POSIX`, `Data::Dumper`, `File::Basename`, `File::Copy`, `Carp`

All modules used are part of Perl's standard library — no CPAN install required.

## Learning Path

Start from `01_basics/01_hello_world.pl` and work through in order.
Each script is self-contained and runnable independently.
